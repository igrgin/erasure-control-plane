- [ ] Validate the measured full-stack resource envelope and updated total cost against the owner-approved hosting decision before provisioning/promoting.
- [ ] Use EPIC-08 immutable deployment/restore machinery; publish a read-only tour and allow owner-controlled temporary live sessions, with no public source/admin credentials or reset endpoints.

- [ ] Record URL, candidate/image digests, seed generation, uptime/cost limits, reset/maintenance owner, backup/recovery evidence, and a working teardown procedure.
- [ ] Publish the recording and architecture explanation as an offline fallback; mark live visibility accepted only after an external browser completes the public tour.

Perform attended UAT from an external browser and one controlled live session; verify access boundaries, fresh fixtures after reset, measured consumption, restart recovery, and final URL evidence.

Retain commands/results and owner review against the exact candidate. Application checks are implemented with the issue; these are acceptance instructions, not claims that tests already exist.
