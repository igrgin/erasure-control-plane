# ERA-040: Build the guided three-source demo and repeatable scenario reset

Epic: [EPIC-10](../epics/EPIC-10.md). Milestone: v0.1 end-to-end demonstration. Status: proposed.

## Acceptance criteria

- [ ] Create a guided read-only tour of inventory, impact, owner approval, execution attempts, blockers, dispositions, and audit; source values are synthetic.
- [ ] Provide owner-controlled temporary operator/source-owner sessions for real end-to-end cleanup, with bounded concurrent runs and private reset/administration.
- [ ] Run healthy PostgreSQL deletion, MongoDB transformation, and Redis invalidation plus retention, precision, isolation, outage, unknown-result, and cache-expiry/recreation scenarios.
- [ ] Show registered-source coverage and adapter-reported outcomes explicitly; fixtures may establish correctness without adding independent deletion verification to Erasure.
- [ ] Reset safely between live runs and produce a short recording with candidate/seed references as an offline visibility fallback.

## Verification

Run browser and fixture-store checks for all three adapters, prove a general visitor cannot administer sources/reset data, and repeat the same live walkthrough after a quiesced reset.

Retain commands/results and owner review against the exact candidate. Application checks are implemented with the issue; these are acceptance instructions, not claims that tests already exist.
